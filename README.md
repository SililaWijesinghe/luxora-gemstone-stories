# LUXORA: Gemstone Stories

Design and build a complete, production-quality luxury gemstone/jewelry website called LUXORA, using the provided blue gemstone showcase video as the hero background video.

The website should feel like a premium international luxury gemstone brand — cinematic, mysterious, sophisticated, editorial, immersive, and extremely polished. The visual direction should closely follow the supplied reference UI: deep midnight backgrounds, dramatic gemstone lighting, elegant serif typography, restrained gold/champagne accents, thin borders, cinematic spacing, and subtle premium interactions.

IMPORTANT:

Do NOT generate replacement hero imagery.

I am providing the actual hero gemstone showcase video. Use that video as the hero background.

The hero video should cover the entire hero section with object-fit: cover.

Add a sophisticated dark gradient overlay over the video so text remains highly readable.

The website must feel like a luxury brand experience rather than a conventional ecommerce template.

Avoid generic SaaS styling, excessive rounded cards, bright gradients, excessive glassmorphism, or colorful UI.

Prioritize cinematic composition, typography, whitespace, subtle motion, and premium micro-interactions.
